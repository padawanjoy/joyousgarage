Anthropic이 Opus보다 한 등급 위 모델을 일반에 풀었습니다. 바로 Fable 5인데요. 지금까지 이 등급에 해당하는 모델은 정부 협력 사이버 방어팀 같은 극소수만 사용할 수 있었습니다. 그게 이번에 누구나 쓸 수 있게 된 건데요. Fable 5가 어떤 모델인지 살펴보겠습니다.

## Mythos-class라는 새 등급

Claude 모델은 Haiku, Sonnet, Opus 순으로 등급이 나눠집니다. Fable 5는 그 위에 새로 생긴 Mythos-class(미소스급) 단계에 속하는 모델입니다. 이 등급의 첫 모델은 지난 4월에 나온 Claude Mythos Preview였습니다. 다만 그 모델은 소프트웨어 취약점을 찾아내는 능력이 너무 뛰어나서, 사이버 우려 때문에 소수 파트너에게만 제한적으로 허용되었었습니다.

Fable 5는 이 Mythos-class 모델에 강력한 안전장치를 붙여서 일반 배포용으로 만든 버전입니다. 안전장치를 뗀 원본은 Mythos 5라고 부르고, Mythos 5 모델은 여전히 검증된 소수 파트너들만 사용할 수 있습니다. Anthropic에서 밝히기로 두 모델은 완전히 같은 모델이며, 차이는 안전장치뿐이라고 합니다. 이 차이 때문에 이름을 다르게 붙였다고 하네요.

## 스펙과 가격

| 항목 | 값 |
|---|---|
| 컨텍스트 | 100만 토큰 |
| 최대 출력 | 128,000 토큰 |
| 지식 컷오프 | 2026년 1월 |
| API 모델명 | claude-fable-5 |
| 추론 방식 | 상황에 맞춰 조절(adaptive) |
| 가격 | 입력 $10 / 출력 $50 (100만 토큰당) |

가격이 먼저 눈에 들어오는데요. Opus 4.8이 입력 $5, 출력 $25니까 정확히 두 배 수준입니다. 추론은 켜고 끄는 방식이 아니라 얼마나 깊게 생각할지를 단계별로 고르는 방식입니다. 이런 설정이 비용과 깊게 관계가 있는데요. 관련해서는 다음 글에서 따로 더 자세히 다뤄보겠습니다.

## Fable 5의 벤치마크

Anthropic은 테스트한 거의 모든 벤치마크에서 최고 수준을 달성했다고 발표했습니다. 자주 인용되는 수치 일부를 추려봤는데요.

| 벤치마크 | 평가 대상과 측정 방식 | Fable 5 | Opus 4.8 | GPT-5.5 |
|---|---|---|---|---|
| SWE-Bench Pro | 실제 대규모 코드베이스의 버그·기능 과제 수정, 신규 테스트 통과와 기존 기능 회귀 여부로 해결률 평가 | 80.3% | 69.2% | 미공개 |
| FrontierCode Diamond | 최고난도 50개 개발 과제에 정확성뿐 아니라 테스트 품질·범위 준수·스타일·유지보수성 등 PR 병합 가능성 평가 | 29.3% | 13.4% | 5.7% |
| Humanity's Last Exam | 수학·과학·인문학 등 전문가급 객관식·단답형 2,500문제로 지식의 폭과 추론력, 답변 정확도·확신 보정도 평가 | 64.5% | 57.9% | 52.2% |

FrontierCode Diamond 결과가 특히 눈에 띄는데요. Opus의 두 배가 넘는 수치인데요. 이 벤치마크는 테스트를 통과하느냐만 보는 게 아니라, 성능과 관례, 장기 유지보수성까지 갖춘 프로덕션급 코드인지 아닌지를 봅니다. 그런 점에서 2배 이상의 성능 향상은 대단한 것 같습니다.

널리 쓰이는 SWE-bench Verified에서는 서드파티 트래커(Vals) 기준 95.0%로, Opus 4.8의 88.6%보다 높게 나왔습니다.

단순 숫자 자체 값보다 주목해야 할 점은 바로 패턴인데요. 작업이 길고 복잡할수록 다른 Claude 모델과의 격차가 벌어지는 모습을 확인할 수 있습니다. 짧은 질답에서는 비싼 Opus 정도로 느껴지다가, 여러 단계로 이어지는 작업에서 그 진가가 확실히 드러나는 거죠.

## Fable 5의 능력

벤치마크 수치도 대단하지만 실제 활용 면에서도 Fable 5가 정말 대단한 모델이라는 것을 알 수 있습니다.

먼저 오래 이어지는 작업에서 수백만 토큰에 걸쳐 방향을 잃지 않고 집중을 유지하는데요. Anthropic 데모 중에는 파일 기반 메모리를 붙였더니 덱빌딩 게임 성능이 Opus보다 세 배 더 개선되었다고 합니다. 그리고 포켓몬 파이어레드를 화면 스크린샷만 보고 끝까지 깼다고도 하고요. 이전 모델들은 보조 도구를 잔뜩 붙여줘도 못 깼던 걸, Fable은 시각 입력만으로 해냈다는 점이 대단한 것 같습니다.

실제로 Fable 5는 이전 모델 대비 비전 능력이 특히 더 향상된 것을 여러 사례를 통해 알 수 있는데요. 스크린샷만 보고 웹 앱 소스코드를 다시 만들어내거나, 복잡한 과학 도표에서 정확한 수치를 뽑아냅니다. 파일과 PDF 안에 들어간 표와 차트도 읽어내고요.

문서 분석이나 자료 조사 같은 작업에서도 대단한 성능을 보였습니다. 금융 추론 벤치마크에서 최고점을 받았고, 문서 기반 추론과 표·차트 해석에서 다른 모델들을 크게 앞섰습니다. 안전장치를 뗀 Mythos 5로는 단백질 설계 과정을 약 10배 빠르게 진행한 내부 사례도 공개가 됐습니다. 다만 이런 생물 쪽 능력은 Fable에서는 대부분 막혀 있어서 우리가 활용해 볼 수는 없습니다.

## 어디서 쓸 수 있나

Fable 5는 Claude 채팅, Claude Code, Cowork, 그리고 API에서 모두 쓸 수 있고, AWS·구글 클라우드·마이크로소프트 파운드리에서도 제공됩니다.

다만 요금 처리 관련해서는 계속 변화가 있는데요. 이 글을 쓰는 시점 기준으로 구독에 포함되는 일정이 계속 연장되고 있긴 하지만, 방향 자체는 구독 요금제에서 Fable 5를 빼고, 사용 크레딧을 따로 사서 쓰는 쪽으로 간다고 합니다. 그런 점을 감안하고 써보시는 게 좋겠습니다.
